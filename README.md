# Mako 現場作業ダッシュボード（試作）

現場のカスタマーエンジニアが残す「作業履歴・申し送り」を、紙 → PDF → ファイルサーバー
という流れから、**現場でスマホ入力 → 会社に構造的に蓄積 → PCでいつでも閲覧**へ置き換える
ためのプロトタイプです。

この試作は **③ 見るアプリ（ダッシュボード）** の部分です。ダミーデータで動きます。

## 全体像

```
[現場エンジニア]              [会社に構造的に蓄積]           [誰でも見れる]
 スマホで入力       ──▶     SharePoint リスト等       ──▶   ダッシュボード (このアプリ)
 ・音声で回答                ・案件 / 顧客ごと                ・現場も
 ・写真添付                  ・写真もひも付け                ・サービスセンターも
   (Microsoft Forms)      (Power Automate で整理)          好きな時に見れる

              ＋ お客からの頼まれごと・残務(TODO)も蓄積 → 残務ボードで追える
```

- **集める** … Microsoft Forms（音声＋写真、スマホ）
- **貯める** … SharePoint リスト（＝そのまま構造化DB）／写真はドキュメントライブラリ
- **整理する** … Power Automate（Forms回答 → リストへ自動転記・フォルダ分け）
- **見る** … このダッシュボード（PC / Python）

## 機能（試作）

- 📊 **サマリー** … 報告件数・未完了残務・期限超過・顧客数、最近の報告と要対応の残務
- 📋 **作業報告** … 顧客／担当者／キーワードで検索、写真つきで一覧
- 🗂️ **残務ボード** … 頼まれごとを「未対応 / 対応中 / 完了」で表示、顧客で絞り込み、期限超過を赤表示
- 🏢 **顧客別** … 顧客ごとの作業履歴と残務をまとめて表示

## 動かし方

```bash
pip install -r requirements.txt
streamlit run app/dashboard.py
```

ブラウザで `http://localhost:8501` が開きます。

## データ（＝将来の Forms 項目設計）

`app/sample_data/` にダミーの JSON を置いています。項目はそのまま Microsoft Forms の
質問項目に対応します。実運用では `app/data.py` の読み込み先を、Forms の回答（Excel/CSV）や
SharePoint リストに差し替えるだけでダッシュボードは動きます。

- `reports.json` … 作業報告（顧客・現場・作業内容・不具合・対応・部品・結果・申し送り・写真）
- `tasks.json` … 残務／頼まれごと（内容・期限・状態・担当・関連報告）

## 構成

```
app/
  dashboard.py        # Streamlit ダッシュボード本体
  data.py             # データ読み込み＆項目定義（差し替えポイント）
  photos.py           # 写真表示（試作はプレースホルダー生成）
  sample_data/        # ダミーデータ
requirements.txt
```
