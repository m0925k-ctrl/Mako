# Microsoft Forms 作成ガイド（そのまま作れる設問リスト）

現場報告と残務を集める2つの Forms を、この通りに作れば、回答を Excel で
エクスポートしてダッシュボードに**そのまま表示**できます（`MAKO_SOURCE=files`）。

> 仕組み：Forms 回答を Excel で書き出す → `templates/mapping.json` を同じフォルダに置く →
> `MAKO_SOURCE=files` で起動。装置・担当のドロップダウンは「ID（読みやすいラベル）」形式にすると、
> ダッシュボードが先頭のIDだけ取り出して自動で結び付けます。

---

## 事前準備：マスタ（1回だけ）

ドロップダウンの選択肢は、装置マスタ・作業員マスタから作ります。
まずは `templates/devices.csv` `templates/engineers.csv` `templates/hospitals.csv` を
自社の内容に埋めてください（Oracle CRM から出力してもOK）。

ドロップダウンの選択肢文言は **「ID（ラベル）」** の形にします（IDが先頭）。
- 装置：`D-MRI-01（MRI装置／さくら総合病院）`
- 担当者：`E01（佐藤 健一）`

---

## フォーム①：作業報告フォーム

| # | 設問（タイトルはこの通りに） | 種類 | 必須 | 選択肢／備考 |
|---|---|---|---|---|
| 1 | 装置 | 選択（ドロップダウン） | ✓ | 装置マスタから「ID（ラベル）」で列挙 |
| 2 | 担当者 | 選択 | ✓ | 作業員マスタから「ID（氏名）」 |
| 3 | 対応区分 | 選択 | ✓ | 定期点検 / 修理 / 緊急対応 / 設置・初期点検 |
| 4 | 作業内容 | 記述（長文） | ✓ | 現場では音声入力で |
| 5 | 発生した事象・不具合 | 記述（長文） |  | |
| 6 | 対応・処置 | 記述（長文） |  | |
| 7 | 使用・交換部品 | 記述 |  | |
| 8 | 結果・動作確認 | 記述（長文） |  | |
| 9 | 次回への申し送り | 記述（長文） |  | |
| 10 | 写真 | ファイルのアップロード（複数可） |  | |

> `完了時刻`（回答日時）と `ID`（回答番号）は Forms が自動で付けるので、設問は不要。
> ダッシュボードでは作業日時・報告IDとして使います。

## フォーム②：残務登録フォーム（短い）

| # | 設問 | 種類 | 必須 | 選択肢／備考 |
|---|---|---|---|---|
| 1 | 装置 | 選択 | ✓ | 「ID（ラベル）」 |
| 2 | 内容 | 記述 | ✓ | 頼まれごと・残務の内容 |
| 3 | 期限 | 日付 |  | |
| 4 | 優先度 | 選択 | ✓ | 高 / 中 / 低 |
| 5 | 担当 | 選択 |  | 「ID（氏名）」 |
| 6 | メモ | 記述 |  | |

> 状態は新規時「未対応」で自動セット（ダッシュボード側の既定）。

---

## 回答を集めたら：ダッシュボードに表示

1. 各フォームの回答を **Excel でエクスポート** → `reports.xlsx` / `tasks.xlsx` にリネーム
2. 1つのフォルダに置く：`reports.xlsx` `tasks.xlsx` `hospitals.csv` `devices.csv`
   `engineers.csv`、そして `templates/mapping.json` をコピー
3. 起動：

```bash
pip install -r requirements.txt
export MAKO_DATA_DIR=/path/to/そのフォルダ
MAKO_SOURCE=files streamlit run app/dashboard.py
```

これで**実データのカルテ・残務**が表示されます。設問タイトルを変えた場合は
`mapping.json`（キー=内部名、値=設問タイトル）を合わせるだけ。

---

## つまずきやすい点

- **装置が結び付かない**：ドロップダウン文言の先頭IDが、`devices.csv` の `id` と一致しているか。
  例）選択肢 `D-MRI-01（…）` と `devices.csv` の `D-MRI-01`。
- **列名が違う**：`mapping.json` の値（右側）を、実際の設問タイトルに合わせる。
- **日付が変**：Excel の日付書式でもOK（自動変換）。うまくいかない時は `YYYY-MM-DD` に。
- **写真**：ファイルアップロードはリンクで入る。試作では枚数の表示のみ（本番は SharePoint 画像に接続）。
